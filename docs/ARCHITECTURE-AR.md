# الدليل المعماري الكامل — شرح كل ملف في المشروع

هذا الدليل يشرح **فائدة كل ملف** في المستودع ودوره في المنظومة، بالعربي،
لقراءة المالك. النسخة الهندسية الإنجليزية المختصرة في `README.md`،
والدستور الملزم في `CLAUDE.md`، ومصدر الحقيقة المنتجي في
`docs/WHITEPAPER.html` + `docs/CHANGELOG-v1.1.md`.

---

## الصورة الكبيرة — خمسة تدفقات

1. **شراء ← تفعيل**: ويبهوك سلة ← تحقق توقيع ← تخزين بلا تكرار ← إعادة تحقق
   من سلة API ← تزويد عند «مدفوع» فقط ← رمز تفعيل (يُخزن مجزّأ) ← العميل
   يرسله واتساب ← يرتبط رقمه بحسابه.
2. **إعداد ← نشط**: موافقة مدمجة ← ١٤ سؤالًا ← رفع CV عبر ست مراحل فحص ←
   تجريد الهوية ثم استخراج Claude ← تأكيد الحقائق في «بنك الإنجازات»
   (المرفوض يدخل قائمة المحرمات) ← تقييم المسار ← سياسة بحث ← نشط.
3. **محرك الليل**: عائلات استعلام مشتقة من مسارات العملاء النشطين ← مصدران
   معزولان ← إزالة تكرار ← Pool مشترك ← إثراء خلف حراس SSRF ← بوابة لكل
   عميل بسجل قرار («ليش أرسلتوها لي؟») ← حجب المكرر قبل السقف ← ترتيب حتمي
   بأثر مُعلَّل.
4. **سيرة ← تسليم ← إغلاق صادق**: توليد Claude بسلسلة حراس (مفردات البنك،
   منع الاختراع، المحرمات، تسرب العربية) ← نشر ذري ← سلطة الربط قبل أي
   إرسال ← حزمة واتساب (بطاقة ← ملف ← أزرار قرار) ← حجب المسلَّم ← حالة
   يومية واحدة صادقة من سبع. الهوية الحقيقية تُحقن محليًا — **ولا نداء LLM
   يرى اسمًا أو رقمًا**.
5. **قمع الاكتساب**: منتج تحليل بـ٢٩ ريال ← نفس سلطات الموافقة والرفع
   والاستخراج ← تقييم حتمي بنفس محرك المسارات ← تقرير عربي RTL ← زر ترقية
   يرث كل شيء.

## `src/career_core/` — النواة النقية (بلا شبكة وبلا قاعدة)

دوال محضة قابلة للاختبار بمعزل عن كل شيء — «عقل» القرارات الحتمية.

| الملف | فائدته |
|---|---|
| `gate.py` | حساب البوابة النقي: تصنيف يقين الراتب، درجات جودة الشركة والدور، ومفتاح الترتيب الحتمي. |
| `salary.py` | قراءة الراتب من نص الإعلان وتصنيفه (معلن مؤكد ← مجهول). |
| `identity.py` | اشتقاق هوية الوظيفة القانونية `joburl-v1` — نفس الهوية للنشر والربط والحجب. |
| `sentences.py` | بوابة جودة الجملة الإنجليزية (§1.6): ترفض الملخص المبتور أو المعلّق. |
| `ssrf.py` | حارس فاشل-مغلق ضد استدراج السيرفر لعناوين داخلية (يفحص قبل وبعد التحويلات). |
| `urltools.py` | تطبيع الروابط وإزالة وسوم التتبع (مفاتيح إزالة التكرار وروابط العرض). |

### `engine/` — محرك الليل (C6)

| الملف | فائدته |
|---|---|

| `families.py` | عائلات الاستعلام مشتقة ديناميكيًا من مسارات العملاء النشطين — لا شيء مثبت بالكود. |
| `sources.py` | مهايئا المصدرين: عزل لكل استعلام، مهلة ٤٥ث بإعادة، تجريد HTML، توجيه رابط التقديم — دروس التشغيل الحي كلها هنا. |

| `enrichment.py` | إثراء الصفحة مرة لكل وظيفة خلف حارسي SSRF (قبل وبعد التحويل)؛ الفشل يُخزن كحكم. |
| `gate.py` | بوابة كل عميل: صرامة السياسة، تكافؤ المناطق، سجل قرار بالأسباب، والتقاط «القريب من النجاح». |

### `cv/` — السيرة الذاتية (C7)

| `close.py` | سلطة الحالات السبع اليومية، إغلاق اليوم، الملخص الإداري، تسجيل الاستخدام وتجميع التكاليف. |
| `daily_run.py` | تنسيق يوم التسليم: عزل كل عميل، إغلاق المعلق المنتهي، الإغلاقات الصادقة، وعدّ التكلفة. |
